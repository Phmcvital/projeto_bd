# Sistema de Gestão Hospitalar - Hospital Universitário Dra. Yuska Maritan Brito

Apenas um norte para o...


Projeto de Banco de Dados focado no gerenciamento de atendimentos, profissionais, pacientes, procedimentos, internações e escalas de plantão do Hospital Universitário Dra. Yuska Maritan Brito.

## 🎯 Objetivos (Etapa 1)
- Modelagem conceitual, lógica e física (DER → MR → SQL)
- Normalização até 3FN/BCNF
- Script SQL para DDL (Criação) e DML (População de dados)
- Consultas SQL essenciais e analíticas

## 🛠️ Tecnologias
- **Banco de Dados:** PostgreSQL
- **Backend:** Python 

## 📁 Estrutura do Projeto
- `/docs`: Diagramas e documentação de modelagem.
- `/sql`: Scripts `.sql` puros para criação e manipulação do banco.
- `/src`: Código-fonte da aplicação Python (Etapas futuras).
